# Fog Timer

Automatic on/off timer for a fog machine that has a 433 MHz wireless remote. It learns the remote's ON and OFF codes, then fires timed blasts with pauses in between — from a touchscreen, your phone, or a weekly schedule.

Built for an Oloaxolx 1200W fog machine (ZQ10016), but it should work with any fog machine whose remote uses a fixed-code 433 MHz signal (most cheap ones do).

There are two versions:

| | **CYD version** (recommended) | **XIAO version** (simple) |
|---|---|---|
| Folder | `cyd_fog_timer/` | `fog_timer/` + `capture/` |
| Board | ESP32 "Cheap Yellow Display" 2.8" touch (Freenove FNK0103) | Seeed XIAO RP2040 |
| Controls | Touchscreen + phone web page | Two knobs + optional button |
| Schedule | Weekly schedule, WiFi time sync | No |
| Learning codes | Built in, from the web page | Separate capture sketch, paste codes into the code |
| Case | 3D-printable STLs in `case/` | None |

Both use the same radio kit: [D-FLIFE 433 MHz transmitter + RX470C receiver](https://www.amazon.com/dp/B0BZRRBBNK).

## CYD version

### Parts
- Freenove ESP32 2.8" touch display (FNK0103, a.k.a. "CYD" / ESP32-32E). Other CYDs work with small pin changes (see below).
- D-FLIFE 433 MHz transmitter + RX470C receiver kit
- 1.25 mm (MX1.25 / PicoBlade-style) connector cables for the CYD's ports
- Small protoboard for the radio modules (optional, for the case)

### Wiring

| Module pin | CYD port / pin |
|---|---|
| RX470C GND | Input pin port GND |
| RX470C DATA (either) | Input pin port IO35 |
| RX470C VCC | Input pin port 3.3V |
| Transmitter DAT | SPI port IO27 |
| Transmitter − | Serial port GND |
| Transmitter + | Serial port 5V |
| Transmitter EN | not connected |

Leave the serial port's RXD/TXD unconnected.

### Building and flashing

**Arduino IDE**

1. Install the board package: **Tools > Board > Boards Manager**, search **esp32**, install **esp32 by Espressif Systems** (3.3.x).
2. Install libraries: **Tools > Manage Libraries**, install **LovyanGFX** and **rc-switch**.
3. Open `cyd_fog_timer/cyd_fog_timer.ino` (keep `web_page.h` in the same folder).
4. Board settings:
   - **Board:** ESP32 Dev Module
   - **Partition Scheme:** Huge APP (3MB No OTA/1MB SPIFFS)
5. Optional: edit the settings block at the top of the sketch — home WiFi, hotspot password, hostname, and time zone (`TZ_INFO`, defaults to US Eastern). WiFi can also be set later from the web page.
6. Plug in the CYD, pick its COM port, and click **Upload**. If it won't connect, hold the **BOOT** button while the upload starts.

**arduino-cli**

```bash
arduino-cli core install esp32:esp32
```

```bash
arduino-cli lib install LovyanGFX rc-switch
```

```bash
arduino-cli compile --fqbn esp32:esp32:esp32:PartitionScheme=huge_app cyd_fog_timer
```

```bash
arduino-cli upload --fqbn esp32:esp32:esp32:PartitionScheme=huge_app -p COM5 cyd_fog_timer
```

(Replace `COM5` with your port, e.g. `/dev/ttyUSB0` on Linux.)

**Other CYD boards:** the RGB LED pins differ on generic CYDs — change `LED_R` from 22 to 4. If colours look inverted, set `cfg.invert = true` in the panel config.

### First-time setup
1. On first boot the screen asks you to tap the corners to calibrate touch. (To redo it later, hold a finger on the screen while plugging it in.)
2. If no home WiFi is set, it starts a **FogTimer** hotspot (password `fogmachine`). Join it and open `http://192.168.4.1`, then enter your home WiFi under **WiFi**. It restarts and shows its address on screen.
3. On your phone, open the address on the screen (or `http://fogtimer.local`). In Chrome, use **menu > Add to Home screen** for an app-like shortcut.
4. Learn the remote: tap **Learn ON**, press ON on the remote close to the receiver. Repeat with **Learn OFF**. Check with **Test ON / Test OFF**.

### Using it
- **Modes:** OFF, ON (cycles blast/pause continuously), SCHED (cycles only inside schedule windows).
- **Blast / Pause:** set with +/− on the screen or the web page. Hold +/− to auto-repeat.
- **FOG NOW** fires a single blast; **STOP** sends OFF and switches the mode to OFF.
- Settings, codes and the schedule survive power loss.

### Case (`case/`)
A wedge desk stand: the screen tilts back 65° on the front, and the radio protoboard screws to the bottom plate behind it.

- `fog_case_shell.stl` — print upside down (flat top on the bed; already oriented that way). No supports needed. PETG recommended.
- `fog_case_plate.stl` — print flat.
- `fog_case_preview.stl` — full assembly, for looking at only.
- Hardware: 4× M3×8 self-tapping (CYD to standoffs), 4× M3×8 countersunk (plate to shell), 4× M2×6 self-tapping (protoboard).
- Stylus holder: a hole in the top (back corner, USB side); the stylus hangs by its clip.
- The receiver's spring antenna won't fit sideways inside; bend it upright.

**Resizing the case:** the STLs are generated by `fog_case.mjs`. If your board or protoboard differs, measure with calipers, edit the values at the top of `fog_case.mjs`, then (with [Node.js](https://nodejs.org) installed) run in the `case` folder:

```bash
npm install
```

```bash
node fog_case.mjs
```

It rewrites the STLs and prints fit checks.

## XIAO version

Seeed XIAO RP2040 with two knobs (blast length 1–20 s, pause length 5–180 s), an optional "fog now" button, and a 1.3" OLED showing status and a countdown.

### Parts
- Seeed XIAO RP2040
- 1.3" I2C OLED (SH1106; SSD1306 also works, see below)
- 2× 10k potentiometers
- Tactile button (optional)
- D-FLIFE 433 MHz transmitter + RX470C receiver kit

### Wiring

| Part | Pin | XIAO RP2040 |
|---|---|---|
| Knob 1 (blast) | outer pins | 3V3 and GND |
| | middle pin | D0 / A0 |
| Knob 2 (pause) | outer pins | 3V3 and GND |
| | middle pin | D1 / A1 |
| RX470C receiver | VCC | 3V3 (not 5V — RP2040 pins aren't 5V-tolerant) |
| | GND | GND |
| | DATA (either) | D2 |
| Transmitter | + | 5V (more range) |
| | − | GND |
| | DAT | D3 |
| | EN | not connected |
| OLED | GND / VCC | GND / 3V3 |
| | SDA / SCL | D4 / D5 |
| Button (optional) | one side / other side | D6 / GND |

The receiver is only needed to record the codes; you can remove it afterwards.

### Building and flashing
1. Arduino IDE: **File > Preferences > Additional boards manager URLs**, add
   `https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json`
   Then in Boards Manager install **Raspberry Pi Pico/RP2040** and select **Seeed XIAO RP2040**.
2. Library Manager: install **rc-switch** and **U8g2**.
3. Upload `capture/capture.ino`, open Serial Monitor at 115200, and press ON and OFF on the remote several times each.
   - Nothing prints at all: your remote is probably 315 MHz — you'll need a 315 MHz transmitter/receiver pair.
   - "couldn't decode" prints: the remote uses a protocol rc-switch doesn't support.
4. Copy the printed `code`, `bits`, `protocol` and `pulse` values into the top of `fog_timer/fog_timer.ino` (`CODE_ON`, `CODE_OFF`, `BITS`, `PROTOCOL`, `PULSE_US`).
5. Upload `fog_timer/fog_timer.ino`.
   - Picture shifted or garbled: your OLED is an SSD1306 — swap the display line as noted in the code.
   - Board not detected on first upload: hold **B** (boot), plug in USB, release, then upload.
6. Power from any USB-C charger.

arduino-cli equivalent (after adding the board URL above with `arduino-cli config add board_manager.additional_urls <url>`):

```bash
arduino-cli core install rp2040:rp2040
```

```bash
arduino-cli lib install rc-switch U8g2
```

```bash
arduino-cli compile --fqbn rp2040:rp2040:seeed_xiao_rp2040 fog_timer
```

## Tips
- Short blasts with longer pauses (e.g. 5–10 s on, 30–60 s off) give the heater time to recover. If a blast stops on its own, the machine is re-heating.
- Weak range: replace the spring antennas with a 17.3 cm straight wire.
- Keep the electronics away from the nozzle (fog residue) and the heater. A 1200 W heater gets hot enough to soften plastic — leave clearance and ventilation if it's inside a tote.
